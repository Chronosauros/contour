Find your VID:PID

Contour does not show it, so here is how to look it up.

Contour does not show the VID:PID or the USB name of a plugged-in device. Its service screen (long-press the status pill in the Library) shows the model name Contour matched, and a short log, but only for a device it already recognises. For an unknown device it tells you nothing, so use one of these instead:

  • On Android: install a USB device info app, plug the DAC in through OTG and open its entry. Look for the vendor ID, the product ID and the product name. Hex values are usually shown as 0x3302 and 0xC20F, which is 3302:C20F here.
  • On Windows: Device Manager, open the device, Details tab, Property: Hardware Ids. You will see VID_3302&PID_C20F.
  • On Linux: run lsusb; the ID column reads 3302:c20f. lsusb -v adds the product name.
  • On macOS: Apple menu, About This Mac, System Report, USB. Vendor ID and Product ID are listed per device.

Copy the USB product name exactly as shown, including any extra spaces: some names carry a trailing or double space, and Contour compares them character by character.

After installing

Connect the dongle and send your first profile to it.

  1. Plug in your DAC. Plug your headphones into the TRN Black Pearl first: without them it does not show up on USB. A Moondrop Dawn Pro 2 needs its custom EQ switched on: according to Moondrop it is off after every plug-in, and both volume buttons held for 2 seconds toggle it. A Moondrop DUSK-SP plays its DUSK-DEFAULT preset after every plug-in: tap CUSTOM EQ on the DAC page to hear what you sent.

  2. Allow USB access when Android asks. Tick "always" to skip this next time.

  3. The status shows CONNECTED with a green dot.

  4. Pick a profile in LIBRARY, then hold HOLD TO SEND until it fills. The profile now shows ON DAC.

  5. Unplug and go. The dongle keeps the sound you sent, on any phone or computer.

On first launch you get three examples: BASS BOOST, SOFTER VOCALS and TREBLE BOOST.

Everything else is in the guide: a 6-minute film with chapters, and the full text.

Updating and your profiles

What keeps your saved profiles safe, and the two things that don't.
  • Updates never touch your saved profiles. Installing over the existing app keeps everything.
  • Switch freely between Google Play and the APK from GitHub. They are the same app with the same signature, so your profiles stay.
  • A copy you built yourself is different. It has a different signature, so an official release can't install over it. Android says "App not installed".
  • Going back to an older version isn't possible without uninstalling.
  • Uninstalling removes your profiles. Back them up first: in the Library, long-press a profile and tap SHARE. See More in the Library in the guide.

Download the APK from GitHub

For phones without Google Play. You install updates yourself.

  1. Download the app file.

    Download Contour 1.7.0

    The file is contour-1.7.0.apk, about 4.1 MB. If the button fails, get it from the latest release page.

  2. Open the downloaded file - from the download notification or your Files app.

    The first time, Android says installing from this source isn't allowed. Tap Settings, turn on Allow from this source for your browser or file manager, go back and tap Install.

  3. Google Play Protect may say "App scan recommended" because it hasn't seen Contour before. Tap Scan app - after the scan the install finishes. You can also check the file yourself.

  4. Open Contour.

Updating later: download the newer APK and install it over the old one. Your profiles stay.

To hear about new versions, watch the repo's releases on GitHub (Watch > Custom > Releases).

Troubleshooting

Fixes for the most common install and connection problems.
"App not installed"
Either a copy you built yourself is installed (different signature), or a newer version is already on the phone. Back up your profiles, uninstall the old copy, then install again.
Play Protect says "App scan recommended"
Google hasn't seen Contour before. Tap Scan app - after the scan the install continues.
The status stays NO DAC
Plug the dongle in again, firmly, without adapters or hubs. The phone must support USB OTG; some phones have an OTG switch in Settings that needs to be turned on.
It says TAP TO CONNECT
Tap it and allow USB access when Android asks.
The dongle plays music, but Contour says NO DAC
Contour connects only to the thirteen DACs in the table above, and shows NO DAC for any other dongle. A Moondrop Dawn Pro 2 that reports the USB name DAWN PRO 2, with a space, is a different version and is not supported. A TRN Black Pearl shows up only with headphones plugged into it. Own a dongle that is not on the list? Help add the next DAC.
A SnowSky Melody stays on NO DAC while FiiO Control is open
While FiiO Control runs in the background it holds the Melody, and Contour cannot connect. Close FiiO Control, then plug the Melody in again.
The dongle disappears after a send
The Kiwi Ears Allegro Mini and the JCally JM12 drop off USB for about a second after each save and the FiiO JadeAudio JA11 for about two, and the Moondrop DUSK-SP restarts; they come back on their own, and Contour waits for them. Android may ask for USB access again: allow it. If a FiiO KA15 stops answering after a save, unplug it and plug it back in.

Still stuck? Ask on GitHub Issues.
