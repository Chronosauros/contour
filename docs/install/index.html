What you need

  • A CrinEar Protocol Micro, Protocol Max, FiiO KA15 or FiiO K13 R2R USB DACContour works with these four DACs for now. The Micro, the KA15 and the K13 R2R are tested on the developer's own hardware, the Max by a community member on a real device.
  • An Android phone with Android 9 or newerIt needs USB host support (USB OTG). Almost every phone with USB-C has it.
  • Nothing elseNo account, no internet connection, no extra hardware.

Contour is unofficial and not affiliated with CrinEar.

Obtainium Recommended

Install once and Contour updates itself from its official releases.

Obtainium is a free, open-source app that installs apps straight from their official GitHub releases and tells you when an update is out.

  1. Install Obtainium first. Get it from its latest release on GitHub. For most modern phones, pick the file ending in arm64-v8a-release.apk.

    It is also on F-Droid. More about it on obtainium.imranr.dev.

  2. On your phone, tap the button below.

    Add Contour to Obtainium

    Nothing happened? Install Obtainium first (step 1), then tap again.

    The first time, Obtainium may ask to send notifications - allow it, that's how it tells you about updates. It may also show a welcome note - tap Okay.

    Contour then appears in its list ("Imported 1 app"). The new version may show as "Unknown" at first.

  3. Pull the list down to check for updates, then tap the download icon next to Contour.

    Android asks once to allow Obtainium to install apps. Turn on Allow from this source, go back and tap Install.

  4. Google Play Protect may say "App scan recommended" because it hasn't seen Contour before. Tap Scan app - after the scan the install finishes.

  5. Done. Obtainium checks for new versions in the background and offers to update. Your profiles stay.

Button does nothing? It only works on a phone that already has Obtainium. You can add Contour by hand instead: open Obtainium, tap Add app, paste this address and tap Add.

Download the APK

No extra app needed. You install updates yourself.

  1. Download the app file.

    Download Contour 1.4.1

    The file is contour-1.4.1.apk, about 3.6 MB. If the button fails, get it from the latest release page.

  2. Open the downloaded file - from the download notification or your Files app.

    The first time, Android says installing from this source isn't allowed. Tap Settings, turn on Allow from this source for your browser or file manager, go back and tap Install.

  3. Google Play Protect may say "App scan recommended" because it hasn't seen Contour before. Tap Scan app - after the scan the install finishes. You can also check the file yourself.

  4. Open Contour.

Updating later: download the newer APK and install it over the old one. Your profiles stay.

To hear about new versions, watch the repo's releases on GitHub (Watch > Custom > Releases), or use Obtainium.

After installing

Connect the dongle and send your first profile to it.

  1. Plug in your Protocol Micro, Max, KA15 or K13 R2R.

  2. Allow USB access when Android asks. Tick "always" to skip this next time.

  3. The status shows CONNECTED with a green dot.

  4. Pick a profile in LIBRARY, then hold HOLD TO SEND until it fills. The profile now shows ON DAC.

  5. Unplug and go. The dongle keeps the sound you sent, on any phone or computer.

On first launch you get three examples: PROFILE 1 (flat), NIGHTFALL and DUSK.

Everything else is in the guide: a 6-minute film with chapters, and the full text.

Updating and your profiles

What keeps your saved profiles safe, and the two things that don't.
  • Updates never touch your saved profiles. Installing over the existing app keeps everything.
  • Switch freely between Obtainium and the direct APK. They are the same app with the same signature.
  • A copy you built yourself is different. It has a different signature, so an official release can't install over it. Android says "App not installed".
  • Going back to an older version isn't possible without uninstalling.
  • Uninstalling removes your profiles. Back them up first: in the Library, long-press a profile and tap SHARE. See More in the Library in the guide.

Troubleshooting

Fixes for the most common install and connection problems.
"App not installed"
Either a copy you built yourself is installed (different signature), or a newer version is already on the phone. Back up your profiles, uninstall the old copy, then install again.
Play Protect says "App scan recommended"
Google hasn't seen Contour before. Tap Scan app - after the scan the install continues.
The Obtainium button does nothing
Obtainium isn't installed yet, or you're on a computer. Install Obtainium on your phone, or use the manual way (Add app, paste the address).
The status stays NO DAC
Plug the dongle in again, firmly, without adapters or hubs. The phone must support USB OTG; some phones have an OTG switch in Settings that needs to be turned on.
It says TAP TO CONNECT
Tap it and allow USB access when Android asks.
Obtainium says "rate limited"
GitHub limits how often apps can check without an account. Try again later, or add a GitHub token in Obtainium's settings.

Still stuck? Ask on GitHub Issues.
