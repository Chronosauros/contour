Kiwi Ears Allegro Mini EQ app for Android

Contour EQ is a free, open-source Android app that reads and writes the parametric EQ stored inside the Kiwi Ears Allegro Mini. The EQ is written into the dongle itself, so it works in every app, with no system equaliser.

What Contour does not do on the Allegro Mini

  • Firmware updates.
  • LOW SHELF and HIGH SHELF filters. Kiwi Ears' own tool offers PEAK only, and so does Contour.
  • A preamp. The Allegro Mini has none, so a profile with a preamp has to be changed before it can be sent.
  • Resetting the DAC.

Contour EQ and Kiwi Ears' web tool

Kiwi Ears' own tool for the Allegro Mini is a web tool. It can reset the DAC (CLEAR), which Contour does not do. For the EQ, Contour offers what Kiwi's tool offers: 5 PEAK bands. Contour's DAC page has GLOBAL GAIN in the same steps as Kiwi's tool. Contour runs on the Android phone the dongle is plugged into, keeps your profiles in a library on the phone and needs no internet or account.

Using Contour with the Allegro Mini

  1. Keep the profile to 5 PEAK bands with no preamp. A profile with more bands, other filter types or a preamp can't be sent until you change it; the red line under HOLD TO SEND says what to change.
  2. Send it with HOLD TO SEND. After each send the Allegro Mini drops off USB for about a second and comes back on its own; Contour waits for it.
  3. Play at 48 kHz, the usual USB rate on Android. The DAC works out its filters as if the stream ran at 24 kHz, so Contour writes each frequency converted for a 48 kHz stream; a player that forces 44.1 kHz shifts every band about 8% down.

Everything else works the same on every DAC: How to use Contour.

Questions about the Allegro Mini

Is there an EQ app for the Kiwi Ears Allegro Mini on Android?

Yes. Contour EQ reads and writes the Allegro Mini's 5-band EQ from an Android phone, and its DAC page sets the EQ switch and GLOBAL GAIN. It is free and open source (Apache 2.0). Kiwi Ears' own tool for this DAC is a web tool.

Do I need a driver or root?

No. Android supports USB audio dongles out of the box, and Contour talks to the Allegro Mini over USB after you allow it in Android's permission prompt. No root, no extra driver.
