0:00Contour 能做什么

Contour 是一款 EQ（均衡器）管理应用，适用于 CrinEar Protocol Micro 和 Max、飞傲（FiiO）KA15、K13 R2R 和 JadeAudio JA11、雪漫天（SnowSky）Melody 和 Tiny A、TRN Black Pearl、水月雨（Moondrop）Dawn Pro 2、Echo-A 和 DUSK-SP、Kiwi Ears Allegro Mini，以及 JCally JM12。EQ 保存在解码器内部，所以无论插到哪台设备上、用哪个应用播放，这份 EQ 都会生效。

视频中使用的是 Protocol Micro，它有 8 个频段；各款解码器的频段和滤波器见下方参数范围与故障排查。

Contour 在 Android 手机上修改这份 EQ，无需账号，也无需联网。首次安装自带三个 EQ 配置，可以作为起点：低频增强（BASS BOOST）、柔和人声（SOFTER VOCALS）和高频增强（TREBLE BOOST）。

0:26连接

插上解码器。TRN Black Pearl 需要先插好耳机。配置库（LIBRARY）右上角的状态标签会显示连接状态：

  • 未检测到 DAC（NO DAC）：没有插入解码器。点按它可以重新检测。
  • 点击连接（TAP TO CONNECT）：已检测到解码器，但 Android 还没有允许访问。点按它，然后选择允许。
  • 已连接（CONNECTED），带绿点：可以开始使用了。

提示：Android 询问是否打开 Contour 时，勾选“始终”，下次插上就会自动连接。

0:57写入配置

点按一个配置，在 EQ 页面打开它。“按住写入”（HOLD TO SEND）是唯一会写入解码器的按钮。按住它直到按钮填满；轻点不会有任何反应。Contour 会写入每个频段和前置增益，逐项回读校验，全部一致才让解码器保存下来。

“已写入 DAC”（ON DAC）表示这个配置现在保存在解码器内部。拔下解码器，到哪里都能用。配置库里也会给它标上“已写入 DAC”，所以你随时知道解码器里存的是哪个配置。

飞傲 KA15。KA15 有三个用户存储位。在“按住写入”上方那一行选择 USER1、USER2 或 USER3；这一行会显示每个存储位当前的名称。Contour 把配置写入所选存储位，并用配置名为存储位命名（最多 7 个字符，可以是字母或数字）。长按存储位可以重命名，不会改动其中的 EQ。读取或写入期间，Contour 会向 KA15 播放一段无声音频流，因为 KA15 只在有音频流输入时才会响应；你的音乐会照常播放。

飞傲 K13 R2R。K13 R2R 有十个用户存储位。在“按住写入”上方那一行选择 1 至 10 号存储位（选中的存储位会在编号下方显示 USER）；Contour 把配置写入该存储位，并将其设为当前生效的存储位。存储位保留各自的 USER 名称。K13 始终使用十个频段，频段较少的配置会用平直频段补满。一次写入大约需要五秒，因为 K13 每次写入后都需要短暂停顿，设置才能在关机后保留。K13 自身的 BYPASS（旁路）模式或自带预设，请在 K13 本机上切换。

飞傲 JadeAudio JA11。它有 5 个频段，滤波器有峰值（PEAK）、低架（LOW SHELF）、高架（HIGH SHELF）、低通（LOW PASS）和高通（HIGH PASS），前置增益范围为 -12 至 +12 dB。Contour 总是把配置写入它唯一的用户存储位 USER1，并将其设为当前生效的存储位，所以无需选择存储位；JA11 自带的预设保持不变。每次写入后，JA11 会从 USB 断开大约两秒，然后自动重新连接，Android 可能会再次询问是否允许 USB 访问：请允许。

雪漫天 Melody 和 Tiny A。两者都有三个用户存储位。在“按住写入”上方那一行选择 USER1、USER2 或 USER3；Contour 把配置写入该存储位，校验后将其设为当前生效的存储位。它们始终使用十个频段，频段较少的配置会用平直频段补满。

水月雨 Dawn Pro 2。它有 8 个频段和一个自定义 EQ，也就是水月雨应用（Moondrop Hub）使用的那个；Contour 把配置写入解码器当前启用的参数均衡（PEQ）组，回读校验，并且从不覆盖解码器自带的预设。自定义 EQ 需要在解码器上打开：据水月雨介绍，每次插上后它都处于关闭状态，同时按住两个音量键 2 秒即可开关。

水月雨 Echo-A。它有 8 个频段，滤波器有峰值（PEAK）、低架（LOW SHELF）、低通（LOW PASS）和高通（HIGH PASS）。高架（HIGH SHELF）由一个低架滤波器加前置增益组合而成，所以它的增益只能取整数 dB，Contour 也可能为此降低前置增益（例如从 -6 降到 -9 dB）。

水月雨 DUSK-SP。这根 DSP 线材有 9 个频段，滤波器有峰值、低架和高架，没有前置增益。Contour 把配置写入它的 CUSTOM EQ（自定义 EQ），从不覆盖水月雨的五个预设。每次写入后，线材会重启，大约需要一秒，Android 可能会再次询问是否允许 USB 访问：请允许。每次插上后，线材播放的是 DUSK-DEFAULT 预设，你的 CUSTOM EQ 仍然保存在线材里。这时，在你选择或修改配置之前，EQ 页面底部的按钮会显示正在播放的预设；点按它打开 DAC 页，再点按 CUSTOM EQ 即可。写入配置后，线材也会切回 CUSTOM EQ。

Kiwi Ears Allegro Mini。它有 5 个频段，只支持峰值，没有前置增益。频段更多、含其他滤波类型或设有前置增益的配置，需要先修改才能写入；“按住写入”下方的红色提示会说明需要改什么。每次写入后，Allegro Mini 会从 USB 断开大约一秒，然后自动重新连接。这款解码器按 24 kHz 的音频流来计算滤波器，因此 Contour 假定使用常见的 48 kHz 音频流，写入按此换算后的频率。

JCally JM12。它有 5 个频段，滤波器有峰值、低架和高架，没有前置增益。搁架滤波器的增益范围为 -6 至 +6 dB，Q 值为 0.7 至 1.0。新的 JM12 出厂时 EQ 处于关闭状态，第一次写入时会把它打开。每次写入后，JM12 会从 USB 断开大约一秒，然后自动重新连接；如果没有重新连接，Contour 会提示你拔下再重新插上。和 Allegro Mini 一样，它按 24 kHz 的音频流来计算滤波器，因此 Contour 写入按常见的 48 kHz 音频流换算后的频率。

USER 存储位。在带 USER 存储位的解码器上，点按一个存储位，解码器就会切换到它，并显示其中的 EQ。如果这份 EQ 已经在你的配置库里，Contour 会打开对应的配置；如果没有，就把它添加为新配置。插上解码器后，Contour 会读取每个 USER 存储位，再切回原来正在使用的那个。在你按住“按住写入”之前，解码器上的任何内容都不会改变。

1:29新建配置

要新建配置，点按带加号的空白卡片。“平直”（FLAT）会给你一个位于 1 kHz 的平直频段。

白色曲线表示 EQ 对声音的作用。每个带编号的圆点就是一个频段：左右拖动调整频率，上下拖动调整增益。长按空白处，就会在那个位置添加一个频段。

1:54滤波类型和滑块

在曲线图下方选择滤波类型：峰值作用于所设频率附近，低架作用于该频率以下，高架作用于该频率以上。部分解码器还有高通（切除该频率以下）和低通（切除该频率以上），飞傲 KA15、K13 R2R 和雪漫天的解码器另有带通（BAND PASS）和全通（ALL PASS）。Contour 只显示你的解码器支持的类型。

频率（FREQ）、增益（GAIN）和 Q 三个滑块从当前位置开始移动，所以手指一碰，数值不会跳变。慢慢拖动可以微调，抬起手指后数值保持不变。

前置增益（PREAMP）设为“自动”（AUTO）时，Contour 会把前置增益降低到刚好让提升的频段不削波。所有改动都会随时保存。

2:23名称和图标

长按卡片可以编辑名称和说明，也可以选择图标。一个好习惯：每副耳机或入耳式耳机（IEM）各建一个配置，并以耳机的名字命名。然后打开配置，用“按住写入”写入解码器。

2:47频段详解

在 EQ 和配置库之间也可以直接滑动切换。

点按圆点或频段标签即可选中该频段。双击圆点，增益归零（0 dB）。双指捏合可以让选中的频段变窄或变宽，这就是它的 Q 值。

+ 标签用于添加频段，最多可加到解码器支持的数量（视频中的 Protocol Micro 为八个）。再点一次已选中的标签，可以“停用”（BYPASS）该频段、“启用”（ENABLE）它，或“删除”（DELETE）它；被停用的频段显示为空心标签。+ 旁边的减号（-）标签会删除选中的频段。撤销即可找回。

3:16精确数值和前置增益

在频率滑块上快速一划，就能扫过整个频率范围。需要精确数值时，点按数字直接输入。

前置增益和频率、增益、Q 一样是一个滑块，旁边有一个“自动”按钮，点按即可打开或关闭自动模式。打开自动时，滑块以较暗的颜色显示 Contour 算出的数值。关闭自动时，可以拖动滑块，或点按数值直接输入，范围是解码器的前置增益范围（见参数范围与故障排查）；在只支持整数 dB 的解码器上，它按整数 dB 调整，显示为 -4 而不是 -4.0，所以你看到的数值就是解码器里保存的数值。写入后声音变小，是前置增益在为提升的频段留出余量。

写入解码器的每个数值都会向音量更小的方向取整，绝不会变得更响。如果自动模式需要的前置增益低于解码器的最低值，或者某个频段无法按你的设置精确保存（比如在 TRN Black Pearl 上用高架大幅提升高音），“按住写入”会被锁定，并用一行红色提示说明原因。减小提升幅度后再写入即可。

3:46对比、撤销、回退

对比。配置处于“已写入 DAC”状态时可以使用 A/B。点按它，EQ 曲线关闭但前置增益保留，这样你能在相同音量下听出差别。再点一次 A/B，EQ 就恢复了。A/B 不会向解码器保存任何内容。A/B 目前仅支持 Protocol Micro，其他解码器暂不支持。

撤销。配置名称旁的两个箭头就像电脑上的 Ctrl+Z：撤销会退回你上一次的改动，无论改的是什么；重做则再前进一步。一次触摸算一步，不管拖动了多远。每个配置最多保留 100 步，关闭应用后依然保留。

清空。“清空 EQ”（CLEAR EQ）只留下一个平直频段。这和其他改动一样，撤销即可立刻恢复。

已保存版本。每个配置都保留一个“已保存”（SAVED）版本，配置库中的卡片显示的就是它。EQ 页面编辑的是工作副本，所以“清空 EQ”不会清空卡片。“按住写入”会保存配置。向右滑动卡片，可以“保存”（SAVE）当前内容，或“恢复”（RESTORE）到上一次保存的版本；向右完全滑到底即保存。视频里显示的仍是 LAST SENT（上次写入），也就是被它取代的旧按钮。

5:06整理、分享、导入

做实验之前，先复制一份会很方便：长按卡片，点按“创建副本”（DUPLICATE）。

向左滑动卡片，可以“归档”（ARCHIVE）或“删除”。两种操作都会提供五秒的“撤销”（UNDO）。

配置库中的更多功能

视频中暂未介绍。

已归档的配置放在配置库底部一个折叠的分区里。展开后，滑动卡片即可“取消归档”（UNARCHIVE）。

长按卡片，点按“分享”（SHARE），配置会以 Equalizer APO 格式的纯文本发送出去。旁边的“保存为 .txt”（SAVE .TXT）会把同样的文本保存为文件，squig.link 和 graph.hangout.audio 都可以导入。也有用户把它导入了拓品（Topping）DX1ii 的网页界面，包括峰值滤波器、搁架滤波器和前置增益。记得在别处留一份备份：配置只保存在你的手机上。

点按 + 卡片，选择“粘贴”（PASTE），可以读取同样的格式，内容可以来自 AutoEQ、Squiglink 或 EQ by Ear 的导出。旁边的“打开文件”（OPEN FILE）读取 .txt 文件；在 .txt 文件的“打开方式”和“分享”菜单里也能找到 Contour。增益为 0 dB 的空滤波器会被跳过。写入前请先检查曲线。

点按 + 卡片，选择“从 DAC 导入”（FROM DAC），会把解码器当前保存的内容存为一个新配置。

向左滑动 + 卡片会出现“全部保存”（SAVE ALL）：把每个配置按当前状态保存，不会向解码器写入任何内容。操作前会先确认，而且无法撤销。

DAC 页与恢复出厂设置

视频中暂未介绍。

自带设置项的解码器，会在 EQ 和配置库旁边多出第三个页面：DAC 页。它只显示你的解码器具备的选项，顶部显示采样率和固件版本：飞傲 KA15 有音量（VOLUME）、音量档位（VOLUME STEPS）、声道平衡（BALANCE）、数字滤波器（FILTER）、输出模式（OUTPUT）、DRE、亮度（BRIGHTNESS）、息屏时间（SCREEN OFF）、屏幕旋转（ROTATION）和语言（LANGUAGE）；雪漫天 Melody 有音量、音量档位、声道平衡、数字滤波器、增益、输出模式、DRE、线控麦克风（IN-LINE MIC）、指示灯（LIGHT）和按键（BUTTONS）；雪漫天 Tiny A 有音量、音量档位、声道平衡、线控麦克风和指示灯；飞傲 JadeAudio JA11 有音量（0 至 60）和线控麦克风。这些解码器上会显示 USB 音频（USB AUDIO，即 UAC），但不能在 Contour 里更改。在 JA11 上更改线控麦克风后，它会像写入后一样从 USB 短暂断开。

TRN Black Pearl 的 DAC 页有数字滤波器（FAST-LL、FAST-PC、SLOW-LL、SLOW-PC 或 NON-OS）、输出模式（H 类或 AB 类，即 CLASS H 或 CLASS AB）、增益（低或高，即 LOW 或 HIGH）和声道平衡（左右各最多 15 级），也就是 WalkPlay 网页工具为它提供的设置项。每项更改都会从解码器回读校验，拔下后依然保留。WalkPlay 网页工具每次连接时都会把前置增益设为 0 dB，所以如果你用过它，之后请再从 Contour 写入一次配置。

CrinEar Protocol Max 的 DAC 页有数字滤波器（与 Black Pearl 相同的五种）、输出模式（H 类或 AB 类）、声道平衡和麦克风增益（MIC GAIN，-15 至 +15 dB）。每项更改都会从解码器回读校验，拔下后依然保留。这里没有增益设置：增益由 Max 机身上的 Eco / Boost 开关决定，每次插上时都以开关为准。

水月雨 Dawn Pro 2 的 DAC 页显示 EQ 序号（EQ INDEX）、全局增益（GLOBAL GAIN）和前置增益（PRE GAIN），仅供查看。Kiwi Ears Allegro Mini 的 DAC 页有 EQ 开关（关或开，即 OFF 或 ON）和全局增益（-18 至 +3 dB，分级调节）；“按住写入”不会改变这个开关的状态。JCally JM12 也有这两项，全局增益分 15 级，每级 1.5 dB，范围 -18 至 +3 dB；在 JM12 上，写入时如果 EQ 处于关闭状态，会自动把它打开。

水月雨 DUSK-SP 的 DAC 页以按钮列出线材的六个预设：CUSTOM EQ（保存 Contour 写入的内容），以及 DUSK-DEFAULT、DUSK-V、DUSK-HARMAN、DUSK-BASS+ 和 DUSK-DIFFUSE-TILTED。点按后线材会立即切换；下次插上后，它又会播放 DUSK-DEFAULT。

飞傲 KA15 和雪漫天 Melody 的 DAC 页底部有“恢复出厂设置”（FACTORY RESET）。“备份并恢复出厂”（SAVE A COPY AND RESET）会先读取你的 USER 存储位、它们的名称和各项设置，保存在手机上，然后重置解码器，并显示有哪些变化。“写回备份”（WRITE THE SAVED COPY BACK）会把存储位和设置恢复回去。重置后，请拔下解码器再重新插上；在 Melody 上，Contour 会一直等你重新插上，没有时间限制，点按“停止等待”（STOP WAITING）即可结束。Tiny A 没有重置按钮，因为它会忽略这条命令。

5:27参数范围与故障排查

PK 峰值，LS / HS 低架 / 高架，LP / HP 低通 / 高通，BP 带通，AP 全通。

Micro 和 Echo-A 没有真正的高架滤波器，所以 Contour 会写入镜像的低架滤波器加前置增益，得到同样的曲线。Max、KA15、K13 R2R、JA11、Melody、Tiny A、Black Pearl、Dawn Pro 2、DUSK-SP 和 JM12 原生支持搁架滤波器，无需镜像。如果 KA15 在保存后不再响应，请拔下再重新插上。

  • 一直显示“未检测到 DAC”？不要用转接头或扩展坞，直接重新插上解码器。TRN Black Pearl 只有插着耳机时才会被识别。
  • 写入失败？再按住一次按钮。通常是解码器松动了。
  • “粘贴”是灰色的？剪贴板里没有 Contour 能识别的 EQ。请重新复制文本。
