帮助

查找你的 VID:PID

Contour 不会显示它，下面是查找方法。

Contour 不会显示已插上设备的 VID:PID 和 USB 名称。在配置库（LIBRARY）中长按状态标签可以打开服务页面，那里会显示 Contour 匹配到的型号和一段简短日志，但只限于它已经识别的设备。对于未知设备，它什么也不会显示，所以请改用以下方法之一：

  • 在 Android 上：安装一款查看 USB 设备信息的应用，通过 OTG 插上解码器，然后打开它对应的条目。找到供应商 ID（vendor ID）、产品 ID（product ID）和产品名称（product name）。十六进制值通常显示为 0x3302 和 0xC20F，在本页写作 3302:C20F。
  • 在 Windows 上：打开设备管理器，双击该设备，切换到“详细信息”选项卡，在“属性”中选择“硬件 Id”。你会看到 VID_3302&PID_C20F。
  • 在 Linux 上：运行 lsusb，ID 一栏显示为 3302:c20f。lsusb -v 还会列出产品名称。
  • 在 macOS 上：依次打开苹果菜单、“关于本机”、“系统报告”和“USB”。每个设备都会列出“供应商 ID”和“产品 ID”。

请原样复制 USB 产品名称，包括多余的空格：有些名称末尾带有空格，或中间有两个连续空格，而 Contour 会逐字符比较。
