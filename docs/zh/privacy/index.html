隐私政策

最后更新：2026 年 10 月 26 日

Contour 是一款离线 Android 应用。它不收集任何个人数据，也不向任何地方发送任何内容。

  • 不联网。本应用不申请联网权限，因此无法通过网络发送或接收数据。
  • 没有统计分析、广告、崩溃报告或账号。以上各项均未内置在应用中。
  • 你的配置留在手机上。EQ（均衡器）配置和设置保存在应用的私有存储空间中。应用数据不包含在 Android 云备份和设备间数据迁移中。Contour 还会在其外部存储空间的应用专属文件目录中，于 Android/data/<package>/files/backup/ 下为配置库文件创建本地副本（包括一份 v1 之前的副本，以及可选的核对用转储文件，即 dump）。这些副本不是云备份，也不能代替导出配置；只要应用还装在手机上，通过连接的电脑就能读取它们。本政策不会删除已有的副本。卸载应用通常会删除应用专属数据，包括这些本地副本。
  • USB。本应用只与你插上的、受支持的 USB 解码耳放（小尾巴）通信，而且只在你通过 Android 的 USB 权限对话框允许访问之后。它会读取解码器的 EQ 设置，并在你要求时写入新的设置。
  • 解码器恢复出厂设置。在恢复出厂设置之前，Contour 会把解码器的 USER 存储位、这些存储位的名称以及解码器的设置保存为一个文本文件，存放在应用的私有存储空间中，以便之后将它们写回。卸载应用会删除这份副本。
  • 剪贴板。当你打开新建配置面板时，应用会读取手机上的剪贴板，以便提供粘贴 EQ 配置的选项；如果你在面板打开期间插上另一个解码器，应用会再次读取剪贴板。任何内容都不会离开手机。
  • 分享。如果你对某个配置使用“分享”（SHARE），Android 的分享面板会把配置文本发送到你选择的应用。
  • 文件。“保存为 .txt”（SAVE .TXT）会把配置写入你在 Android 文件对话框中选择的文件和位置。当你用 Contour 打开 .txt 文件，或把 .txt 文件分享给 Contour 时，它只读取该文件，向你显示读取到的内容，并在你确认后导入；新建配置面板中的“打开文件”（OPEN FILE）会读取你选择的文件。本应用没有存储权限。
  • 权限。振动，用于触感反馈。对解码器的访问权限在 Android 的 USB 对话框中授予（见上文“USB”）。除此之外没有其他权限。
  • 本网站。contoureq.app 使用 Vercel Web Analytics 统计匿名访问，不使用 Cookie。根据 Vercel 的说明，访客仅通过由请求生成的哈希值来识别，该哈希值会在 24 小时后被丢弃，且统计数据不会与任何个人或 IP 地址相关联。

如有疑问，请在 https://github.com/Chronosauros/contour/issues 提交 issue。
